# 03. WebUI 界面

## 文件

```
webroot/
├── index.html   页面结构
├── app.js       ksu.exec 兼容层、参数校验、事件
└── style.css    主题变量、毛玻璃、组件
```

无构建步骤，直接放进模块目录。KernelSU/APatch 安装时自动设置 `webroot` 权限和 SELinux 上下文，不要手动 chmod。

## 页面模块

| 区块 | 内容 |
|---|---|
| 状态 | 运行中/已停止、地址、PID、数据目录 |
| 版本与更新 | 当前/最新版本、架构、资产、检查更新、立即更新 |
| 下载配置 | 端口、Token、目标路径、离线引擎、删除策略、预设路径 |
| 管理员账号 | 用户名（可选）、新密码、确认密码 |
| 存储 | 列表、启用/禁用、全部重载 |
| 离线任务 | 进行中任务、进度、取消 |
| 迁移 | 数据目录、二进制路径、脚本路径自检/修复 |
| 日志 | `service.log` 尾部、刷新、清空 |
| 关于 | 版本、模块目录、二进制、项目链接 |

## 主题

三态：**自动 / 浅色 / 深色**，顶部右侧按钮循环切换。

- 状态落在 `html[data-theme="light|dark"]`，CSS 只维护两套变量
- 自动模式监听 `matchMedia('(prefers-color-scheme: dark)')`
- 选择存 `localStorage`，键名 `openlist.theme`
- `color-scheme` 跟着主题走，让表单控件按对应模式渲染

不使用三套选择器叠加，避免 `auto` 和 `dark` 同时命中。

## 毛玻璃

- 卡片 26px 圆角、半透明背景、`backdrop-filter: blur(24px) saturate(170%)`
- `body::before` 铺三层径向光斑，给毛玻璃提供底色
- 边框、阴影、内高光统一用变量
- 不支持 `backdrop-filter` 时用 `@supports` 降级成不透明卡片

按钮、输入框、日志框、toast 共用同一套圆角和材质。

## 自定义组件

### 下拉

不用原生 `<select>`：它的弹层由系统渲染，深色页面下会出现白底 + 浅色文字，`option` 样式和 `color-scheme` 都压不住。

改为 `.select`：

```
.select > .select-btn + .select-menu[hidden]
```

- 点击按钮展开，点选项写入 `dataset.value`
- 点击页面其他位置收起
- 选中项高亮，颜色完全由页面控制

### 预设路径

迁移页用 `.chips > .chip-btn`：

- 点击填充输入框并高亮
- 手动输入时自动匹配高亮
- 保留自定义输入，不限制在预设里

## 无 root 接口时的降级

没有 `window.ksu`（普通浏览器打开）时：

- 顶部显示「无 root 接口」
- 状态、日志、存储、任务显示说明文字
- 操作按钮全部禁用
- 主题切换、下拉、预设仍然可用，方便预览界面

## 渲染安全

- 所有命令输出、日志、存储/任务字段用 `textContent` 或 DOM 节点，不拼 `innerHTML`
- 不引外部 CDN，WebUI 离线运行
- 用户输入在 JS 侧先校验，`control.sh` 再校验一次
- Token 输入框默认 `type=password`

## 更新进度

`control.sh update` 把 `stage=` 写到 `/data/local/tmp/openlist_update.progress`，WebUI 每秒读取，映射成中文阶段：

```
resolve → 获取版本信息
download → 下载二进制
extract → 解压
stop → 停止服务
replace → 替换二进制
start → 启动服务
```
