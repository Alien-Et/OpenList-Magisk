# 02. 总结

本次新增 `control.sh` 和 `webroot`，解决三件事：

1. **入口统一**：启停、更新、改配置、改密码、迁移都走 `control.sh`，WebUI 和终端共用，不再各写一套。
2. **覆盖三家**：KernelSU/APatch 用 WebUI，Magisk 用命令行，功能不缩水。
3. **可回滚**：二进制替换前备份 `.bak`，迁移先复制后校验，失败不丢原数据。
