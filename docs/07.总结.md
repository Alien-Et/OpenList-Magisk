# 07. 总结

## 这次做了什么

- **`control.sh`**：所有业务逻辑收到这里，状态、启停、更新、日志、配置、账号、存储、任务、迁移、路径修复都在里面。输出统一 `key=value`，失败带原因。
- **`webroot/`**：KernelSU / APatch 的模块 WebUI，纯静态、无构建步骤，毛玻璃 + 大圆角，主题三态。
- **`customize.sh`**：音量键选二进制位置和数据目录，可选把旧数据一起迁过来。
- **`uninstall*.sh`**：从 `service.sh` 读路径，不再写死。

## 几个关键决定

1. **逻辑只在 `control.sh`**：WebUI 只负责传参、校验、渲染，Magisk 用户在终端调同一份脚本，三家行为一致，不用维护两套。
2. **改密走管理 API**：`GET user/get` → 改字段 → `POST user/update`，在线生效不重启。必须提交完整 User 对象，漏字段会被清零。
3. **迁移 = 移动**：复制 → 文件数 → `data.db` md5 → 改 `config.json` 绝对路径 → 才删源。哪一步不过都保留源目录。
4. **更新先启动成功再写版本号**：起不来就回滚 `.bak`，版本号不动，避免「显示新版本、实际跑旧的」。
5. **`/system/bin` 映射到模块目录**：overlay 写入重启即丢，写真实文件靠模块挂载。
6. **不用原生 `<select>`**：系统弹层压不住样式，深色下白底白字，自己写下拉。
7. **更新放后台跑**：宿主 exec 会把子进程一起收走，长下载必须 `setsid` 脱离，前端轮询拿进度。

## 踩过的坑

| 坑 | 处理 |
|---|---|
| `module.prop` 版本不同步 | 启动成功后才写 version/versionCode |
| 更新起不来不自动回滚 | 恢复 `.bak` 并重启旧版 |
| 迁移后 `config.json` 还指旧路径 | 迁移时同步四个绝对路径 |
| `$MODDIR` 从文本读出来不展开 | `expand_moddir()` 换成真实路径 |
| 相对路径调用时 `MODDIR="${0%/*}"` 拿到文件名 | 统一 `cd + pwd` 转绝对 |
| `getevent` 不可用时菜单空转 | 约 90 秒无输入按默认选项走 |
| 卸载无条件删数据 | 默认只删二进制，`touch .delete_data_on_uninstall` 才连数据删 |
| admin 未初始化时 `/api/admin/*` 全 500 | 交给网页安装向导创建管理员 |
| `module.prop` 显示 172.x 虚拟网卡 | IP 取默认路由的 `src`，排除 `172.16-31` |
| 二进制/数据目录可能同时存在多份 | 加 `scan` / `clean-bins` / `delete-data` / `use-data`，WebUI 里叫「路径体检」 |
| `storage/list` 返回分页对象被当数组 | 前端兼容 `data.content`，请求补 `page`/`per_page` |
| 密码框在某些 WebView 里输不进字 | 不用 `type=password`，改 `text` + 文字遮罩 |
| 更新只弹一句「更新失败」 | 改后台跑，失败原因走 `error=` → stderr → 退出码 |
| 只看到 MIT 徽章就以为打包的二进制也是 MIT | README 顶部写明双许可，安装包内附 `LICENSE-AGPL-3.0.txt` + `THIRD-PARTY.md` |

## 测试覆盖

- 假模块目录：status / start / stop / config-save / migrate-data / migrate-bin / passwd / fix-paths
- 非法输入：端口 `99999`、`0` 被拒，路径注入字符被拒，中文路径通过
- 真实更新：拉 165MB arm64 包，md5 通过，替换成功；坏包触发回滚
- 迁移：`config.json` 四个绝对路径全部对齐；`fix-paths` 能修 `action.sh` 和 `config.json`
- 安装：12 种选项组合全部 `exit=0`，落点和 `service.sh` 变量符合预期（细节见 [06](06.安装选项矩阵.md)）
- 运行时：用 `ip`/`getprop`/`ss` 桩跑 `service.sh`，能拉起进程并把 description 改成「【运行中】当前地址…」
- 卸载：无标记只删二进制；有 `.delete_data_on_uninstall` 才删整目录

## 还没做的

- Magisk 没有 WebUI 入口，只能终端调 `control.sh`
- `action.sh` 还是独立逻辑，没并进 `control.sh`
- `passwd` 假定 admin 的 id 是 1
- 更新没有断点续传和空间检查
- `config.json` 没有可视化编辑
- 安装时在线下载二进制（精简包）还在征求意见，见根目录 README
