迁移

数据目录迁移
点选目标目录即可（当前使用中的不会显示）。目标必须为空目录或不存在。
会停止服务 → 复制 → 校验文件数与 data.db → 修改 service.sh → 启动。跨分区（/data → /sdcard）会丢失属主权限，SQLite 性能也会下降。
二进制路径迁移
点选目标位置即可（当前使用中的不会显示）。
会停止服务 → 复制 → chmod → 修改 service.sh / action.sh → 删除旧位置的二进制 → 启动。
脚本路径自检 / 修复
迁移后如果 service.sh、action.sh 或 config.json 还指向旧路径，点这里一次性对齐。
